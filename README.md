# Mihisara Grocery E-Commerce Website

An Agile-based e-commerce web application developed for **Mihisara Grocery Store** to support online grocery browsing, ordering, inventory management, delivery tracking, and business administration.

## Project Overview

Mihisara Grocery Store currently operates mainly through physical store-based sales. Customers need to visit the shop to browse products, check availability, and purchase grocery items. This creates limitations such as customer inconvenience, manual workload, stock checking delays, and difficulty in managing orders and delivery updates.

This project proposes a web-based e-commerce system that allows customers to browse grocery products online, add items to a cart, place orders, make or simulate payments, and track order or delivery status. The system also includes an admin dashboard for managing products, stock, orders, customers, suppliers, riders, reviews, FAQs, and reports.

## Main Objectives

* Provide an online grocery shopping platform for Mihisara Grocery Store.
* Allow customers to browse products, search items, and place orders online.
* Support customer registration, login, cart, checkout, and order tracking.
* Provide an admin dashboard to manage business operations.
* Improve inventory accuracy through product and stock management.
* Support delivery rider assignment and delivery status updates.
* Include a basic AI Store Assistant for common customer questions.
* Generate dashboard summaries and reports for better decision-making.

## Project Methodology

This project follows the **Agile Scrum methodology**. The development process is divided into multiple sprints, allowing the team to build the system step by step, review progress regularly, and improve the system based on feedback.

Main project stages include:

1. Requirement gathering and analysis
2. Planning and sprint setup
3. UI/UX designing
4. System development
5. Testing and validation
6. Deployment and final review
