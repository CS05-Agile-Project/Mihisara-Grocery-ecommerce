---

## 📌 Project Overview

**Mihisara Grocery E-Commerce Website** is an Agile-based academic project designed to digitally transform the daily operations of Mihisara Grocery Store.

Currently, customers need to visit the physical store to check product availability, compare prices, and purchase grocery items. This manual process can create delays, customer inconvenience, overcrowding, and difficulties in managing stock, orders, suppliers, riders, and reports.

This system provides a centralized online platform where customers can browse grocery products, add items to a cart, place orders, make or simulate payments, and track delivery progress. It also includes an admin dashboard to manage products, inventory, orders, customers, suppliers, delivery riders, reviews, FAQs, and reports.

---

## 🎯 Project Objectives

* Provide an online grocery shopping platform for Mihisara Grocery Store.
* Allow customers to browse products and search grocery items easily.
* Support customer registration, login, cart, checkout, and order placement.
* Enable customers to track order and delivery status.
* Provide an admin dashboard for managing store operations.
* Improve product, stock, order, supplier, and rider management.
* Reduce manual workload and improve business accuracy.
* Include a basic AI Store Assistant for customer support.
* Generate dashboard summaries and reports for decision-making.
* Deliver a responsive, secure, and user-friendly web application.
